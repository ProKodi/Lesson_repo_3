# Подготовка

Установка Linux Server + Docker - за кадром

## Обновление системных пакетов

```Shell
sudo apt update &&
sudo apt upgrade -y &&
sudo reboot
```

# Установка DBaaS

## Подготовка папки под DBaaS

```Shell
sudo mkdir -p /opt/dbaas
cd /opt/dbaas
pwd 
# must be^ /opt/dbaas
```

## Создание docker-compose

```Shell
sudo nano /opt/dbaas/docker-compose.yml
```

```YAML
services:
  postgres:
    image: postgres:18
    container_name: dbaas-postgres
    restart: unless-stopped

    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres_admin_password
      POSTGRES_DB: postgres

    ports:
      - "5432:5432"

    volumes:
      - postgres_data:/var/lib/postgresql

volumes:
  postgres_data:
```

## Запускаем PostgreSQL

```Shell
cd /opt/dbaas
sudo docker compose up -d
sudo docker ps
# Результат примерно такой
# CONTAINER ID   IMAGE         STATUS          PORTS
# xxxxxxxx       postgres:18   Up ...          0.0.0.0:5432->5432/tcp
```

```Shell
sudo docker logs dbaas-postgres
# Смотрим логи:
# Если PostgreSQL запущен то в конце будет что-то вроде:
# database system is ready to accept connections
```

Для подключения в **DataGrid необходимо определить:**

* ip машины
* порт на котором рабоает PostgreSQL
* пароль
* юзера
